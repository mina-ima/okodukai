# お小遣い帳 取扱説明書

> スマホやパソコンのブラウザで使える、シンプルなお小遣い・収支管理アプリです。

## このアプリでできること

- お小遣いやおこづかいの「入金（もらった）」「出金（つかった）」を記録できます。
- 記録するたびに、いまの残高が自動で計算されます。
- 月ごとの収入・支出・差し引き（残った金額）をまとめて確認できます。
- 目標金額（goals）やよく使う金額のプリセット（presets）を登録して、入力をラクにできます。
- データはCSVファイル（`allowance.csv` ほか）に保存されるので、表計算ソフトでも開けます。

> 注記: 上記はソースコード（収支記録・残高計算・月次集計・CSV保存）から確認できた範囲です。画面上の細かな操作ボタンの一部は未確認です。

## 想定ユーザー・利用シーン

- お小遣いの管理を始めたいお子さんや、その保護者の方。
- かんたんな収支メモをスマホで付けたい方。
- 専用アプリを入れず、ブラウザだけで使いたい方。

## 動作環境・前提

- パソコン、またはスマートフォンのブラウザ（Chrome / Safari など）。
- アプリ本体を動かすために Python 3 が必要です（パソコンで起動する場合）。
- Android アプリとしても配布できる構成になっています（`buildozer.spec` を同梱）。

## セットアップ

### パソコンで使う場合

1. このアプリのフォルダ（`okodukai`）を用意します。
2. パソコンに Python 3 がインストールされていることを確認します。
3. ターミナル（コマンド画面）でフォルダを開き、後述の「起動コマンド」を実行します。

### Android アプリとして使う場合

- 同梱の `buildozer.spec` と `ANDROID_DEPLOYMENT_GUIDE.md` を参照してください（ビルド手順が記載されています）。

## 使い方（ステップbyステップ）

1. アプリを起動すると、ブラウザで `http://127.0.0.1:8000` の画面が開きます（Android では自動で開きます）。
2. 「入金」または「出金」を選び、項目名（例: おこづかい、おかし など）と金額を入力します。
3. 登録すると、いまの残高が自動で計算されて表示されます。
4. 月の集計を見ると、その月の収入・支出・差し引きが確認できます。
5. よく使う金額は「プリセット」に、貯金の目標は「目標」に登録しておくと、次回から入力がラクになります。

## 主な機能

| 機能 | 説明 |
| --- | --- |
| 収支の記録 | 入金・出金を日付・項目・金額で記録 |
| 残高の自動計算 | 記録のたびに最新残高を計算 |
| 月次集計 | 指定した月の収入・支出・差し引きを表示 |
| 目標（goals） | 貯金の目標金額を登録 |
| プリセット（presets） | よく使う金額・ラベルを登録 |
| CSV保存 | `allowance.csv` などにデータを保存 |

## よくある質問・トラブルシューティング

- **Q. 画面が開きません。**
  A. アプリ（サーバー）が起動しているか確認してください。起動後にブラウザで `http://127.0.0.1:8000` を開きます。
- **Q. データはどこに保存されますか？**
  A. アプリのフォルダ内の `allowance.csv`（収支）、`goals.csv`（目標）、`presets.csv`（プリセット）に保存されます。
- **Q. ポート番号を変えたい。**
  A. 環境変数 `ALLOWANCE_PORT`（既定 8000）や `ALLOWANCE_HOST`（既定 127.0.0.1）で変更できます。
- **Q. データを引っ越したい。**
  A. CSVファイルをコピーすれば、別の環境にデータを移せます。

## 開発者向けメモ

- **技術スタック**: Python 3 標準ライブラリの `http.server`（軽量HTTPサーバー）。フロントはサーバーが返す単一HTML（インラインCSS/JS、ダークモード対応・モバイル最適化）。データは CSV ファイル管理。
- **主なファイル**: `main.py`（起動エントリ。サーバーをスレッド起動し、Android では `android.open_url` でブラウザを開く）、`allowance.py`（HTTPハンドラ・収支ロジック・HTML）。
- **起動コマンド（パソコン）**:
  ```bash
  python3 main.py
  # または
  python3 allowance.py
  ```
  起動後、ブラウザで `http://127.0.0.1:8000` を開く。
- **環境変数**: `ALLOWANCE_HOST`（既定 `127.0.0.1`）、`ALLOWANCE_PORT`（既定 `8000`）。
- **Android ビルド**: `buildozer`（`buildozer.spec` 同梱）。詳細は `ANDROID_DEPLOYMENT_GUIDE.md` を参照。
- **本番URL**: なし（ローカル/Android アプリ前提。常設の公開URLは未確認）。
- **リポジトリ**: https://github.com/mina-ima/okodukai
